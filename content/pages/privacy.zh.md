# 隐私政策

**最后更新：2026 年 11 月 21 日**

GoFurry Lite 是一个静态生成的导航网站。本站不要求用户注册或登录，不中转前往第三方网站的访问流量，也不会主动要求访问者提供敏感个人信息。

本页说明使用本站时可能涉及的数据及其处理方式。

## 我们不要求提供的信息

GoFurry Lite 不提供用户账号与个人资料管理系统，不要求访问者提供真实姓名、身份证件、支付信息、账号密码、私信内容或精确位置信息。

如果您通过 GitHub 联系我们，您主动提交的信息将依据 GitHub 的服务与隐私规则处理。

## 浏览与搜索

本站目录页面以静态内容形式提供，网站搜索、游戏搜索与内容筛选主要在您的浏览器中完成。

使用这些功能不需要个人账号。Lite 也不再运行旧站面向用户的网站监测与热度统计服务。

## 本地偏好设置

本站可能使用浏览器的 localStorage 保存部分界面偏好，包括亮暗主题以及 SFW/NSFW 内容展示模式。

这些设置仅用于在不同访问之间保留您的显示偏好，不构成用户账号，也不以识别个人身份为目的。

您可以通过浏览器的网站数据管理功能清除这些设置。

## 静态托管、缓存与基础日志

GoFurry Lite 通过 Cloudflare 提供静态内容分发。为了正常提供和保护网站，托管及网络基础设施可能处理 IP 地址、请求时间、浏览器或网络相关的技术信息。

浏览器缓存和网络缓存也可能用于改善页面加载速度与服务稳定性。

Lite 不再运行独立的 Redis 用户访问追踪服务。

## 第三方资源与外部链接

部分游戏图片及视频通过 Steam 的内容分发服务加载，浏览器访问这些资源时，可能向对应的第三方服务发送网络请求。

当您点击外部网站或游戏商店链接时，将离开 GoFurry Lite。第三方服务可能拥有自己的 Cookie、账号、统计及隐私政策。

建议您在使用这些服务时了解其相关规则。

## 联系与更正

如果您认为本站的收录资料涉及个人隐私、版权问题、错误内容，或者需要更正、隐藏或移除，可以通过 [GoFurry Lite GitHub Issues](https://github.com/librecosta/gofurry-lite/issues) 联系维护者。

我们会根据具体情况审阅相关信息，并考虑采取适当的更正、限制展示或移除措施。
